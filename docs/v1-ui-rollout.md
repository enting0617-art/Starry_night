# v1.0 双模式界面推进记录

## 本次交付：P1 + P2 第一版

- 设计令牌：星夜蓝、月光白、圆角、焦点样式和减少动画偏好。
- 双模式 App Shell：陪伴模式与工作台模式可直接切换，偏好保存到浏览器本地。
- 工作台：概览、任务工作台、长期记忆、成长档案、图像与表情、工具与诊断入口。
- 数据一致性：两种模式复用同一个活动会话、消息列表、生成请求和语音队列；不会在切换时重新加载或复制聊天记录。
- 日历：仅提供清晰的“即将加入”入口，尚未创建假日程或假提醒。

## 后续顺序

1. 抽离 ChatController / VoiceController，使聊天生命周期完全不依赖 React 页面结构。
2. 建立 SQLite 版本迁移和本地 Calendar / Reminder API，再实现确认式日程草案与提醒恢复。
3. 增加活动中心、设置的权限说明与可回看的操作记录。
4. 最后验证 Electron 打包、通知、托盘、备份与全新 Windows 安装流程。

## 验收要点

- 模式切换不停止正在生成的回答，也不创建新会话。
- 工作台对记忆与成长档案的编辑、固定、删除继续使用现有本地 API。
- 深色、浅色主题都具备键盘焦点样式；用户启用系统“减少动态效果”时，会压低界面动效。
