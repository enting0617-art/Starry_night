# 星空本地 AI 聊天平台

星空是一个以 **Ollama 本地模型**为核心的个人 AI 聊天平台。项目支持流式对话、长期记忆、AI 独立笔记本、图像理解、本地表情包、联网搜索和 GPT-SoVITS 语音，同时尽量把模型、端口、提示词、数据目录和功能开关保留为可配置项。

当前版本：`0.11.0`

## 主要功能

- 使用 Ollama 本地模型聊天，不依赖云端大模型账号。
- 回答和思考过程流式显示，并可随时停止生成。
- 聊天记录、长期记忆、AI 笔记和表情包数据全部保存在项目文件夹中。
- 支持上传图片，让视觉模型理解图片内容。
- 支持批量识别和管理本地表情包。
- 每次正常回复附带一张数据库中真实存在的表情包，不允许模型虚构表情包地址。
- 支持可选联网搜索，自动处理当前时间、汇率、天气和近期新闻等时效问题。
- 支持浏览器语音与本地 GPT-SoVITS，可手动播放或开启自动播报。
- 内置后台调试页、健康检查、日志和安全调试终端。
- 角色名为“星空”，角色提示词可以独立编辑。

## 运行环境

- Windows 10 或 Windows 11。
- [Node.js](https://nodejs.org/) 22.5 或更高版本，推荐使用 Node.js 24。
- [Ollama](https://ollama.com/) 已安装并可以正常运行。
- 至少安装一个聊天模型。
- 如需本地声音，需要准备可用的 GPT-SoVITS 环境。

## 快速开始

### 1. 准备 Ollama 模型

先启动 Ollama，然后在 PowerShell 中安装需要的模型，例如：

```powershell
ollama pull qwen3.5:4b
ollama pull qwen3.5:9b
ollama pull gemma4:12b
```

模型用途建议：

| 模型 | 建议用途 |
| --- | --- |
| `qwen3.5:4b` | 速度较快，适合普通聊天和基础图像理解 |
| `qwen3.5:9b` | 回答质量更高，但占用更多内存 |
| `gemma4:12b` | 可作为较大的视觉模型使用 |

模型名称不是写死的。只要模型已安装到 Ollama，就可以在设置页选择。

### 2. 启动平台

双击项目根目录中的 `start.bat`。

启动器会自动：

1. 检查 Node.js 和项目依赖。
2. 在首次启动时安装依赖并构建前端。
3. 检查 Ollama、数据库和语音服务状态。
4. 从 `4173` 开始寻找空闲端口。
5. 打开浏览器进入聊天页面。

也可以在 PowerShell 中启动：

```powershell
cd C:\Users\entin\Desktop\3.4\BE
.\start.bat
```

如果双击后一闪而过，请从 PowerShell 运行上面的命令，这样可以看到具体错误。

## 基本使用

### 聊天与停止生成

选择一个 Ollama 模型后即可发送消息。回答会流式显示，生成期间发送按钮会变成停止按钮。

停止后会同时取消浏览器请求和服务器端生成，并保留已经生成的内容。平台默认不设置人为的回答长度、思考字符数和生成时间上限，但实际长度仍会受到模型上下文、内存和 Ollama 配置限制。

### 图像理解

点击输入框附近的图片按钮，可以上传 `PNG`、`JPEG`、`WebP` 或 `GIF` 图片。单张图片默认最大为 8 MB。

平台会优先使用设置中的视觉模型。选择“自动”时，会从已安装模型中寻找支持图像的模型。纯文本模型无法可靠理解图片。

### 表情包

本地表情包存入 `data/emojis.sqlite`，每张图片都有数据库序列号、英文文件名、图片数据、表情包描述、文件类型、大小和校验信息。

表情包管理页支持搜索、预览、修改描述和批量 AI 识别。批量识别采用逐张处理，可以随时停止，避免一次性加载大量图片导致内存溢出。

模型只负责表达回复内容和挑选意图，最终表情包由服务器从数据库中验证并附加。不存在的序列号不会生成图片链接；如果模型忘记选择，服务器会从真实表情包中补选一张。

导入项目 `表情包` 文件夹中的图片：

```powershell
npm run emojis:import
```

### 联网搜索

点击聊天页的地球按钮可以开启或关闭联网搜索。开关默认按当前浏览器保存。

开启后，系统会根据问题自动决定是否搜索：

- 当前时间直接读取服务器本地时间。
- 汇率、天气、新闻、价格、政策、比赛结果等时效问题优先联网。
- 用户明确说“搜索”“查一下”“联网看看”时强制搜索。
- 稳定的常识或普通闲聊通常不会搜索。

搜索结果会作为不可信参考资料交给模型，并要求模型给出来源。联网搜索会把搜索关键词发送给外部搜索服务，这是本项目默认情况下少数会离开本机的数据。

### 可选本地 AI 搜索底座

项目新增了可选的 SearXNG 搜索工具层，提供本地缓存、Wikipedia 查询、网页正文提取、robots.txt 检查和 SSRF 防护。它默认不会替换现有 DuckDuckGo 搜索；确认 Docker 可用后，才按以下方式启用：

```powershell
docker compose -f .\docker-compose.search.yml up -d
```

首次启动前，请将 `searxng/settings.yml` 中的 `secret_key` 替换为随机字符串。随后在 `config.local.json` 写入：

```json
{
  "webSearch": {
    "provider": "searxng",
    "endpoint": "http://127.0.0.1:8888"
  },
  "search": {
    "agentEnabled": true
  }
}
```

启用工具循环前，建议将聊天模型切换为已验证支持 Tools 的 `qwen3.5:9b`。启用后，星空会先让本地模型在最多 4 轮、最多 8 次调用内决定是否执行 `web_search`、`wiki_search` 和 `read_url`，再把实际来源交给最终流式回答。任一工具不可用时会自动回退到原有搜索路径。

可用的本地工具接口包括 `POST /api/search-tools/web_search`、`POST /api/search-tools/wiki_search`、`POST /api/search-tools/read_url` 与 `GET /api/search-tools/health`。网页读取会拒绝 localhost、私网地址和 robots.txt 禁止的路径，搜索缓存仅保存在 `data/search-cache.json`，不会进入长期记忆。

### 语音

语音默认采用“生成后手动点击播放”的模式，避免切换到下一条消息后仍继续播报。每条 AI 消息下面都有“听语音”按钮。

设置页可以选择浏览器语音或 GPT-SoVITS、开启或关闭自动播报、停止当前语音，以及调整语速、音量和音色配置。

语音任务使用队列管理；切换、停止或重新播放时会取消不再需要的任务。语音缓存有数量和容量上限，默认最多保留 40 项、128 MB，避免长期运行造成内存持续增长。

如需启动项目附带的 GPT-SoVITS，请运行：

```powershell
.\start-voice.bat
```

当前音色参考音频位于 GPT-SoVITS 文件夹内，由 `config.local.json` 或 `config.json` 中的语音配置指定。移动项目后请检查该路径是否仍然有效，推荐使用相对于项目根目录的路径。

## 记忆系统

平台有两层长期信息。

### 长期记忆

存放在 `data/memories.json`。系统可以从对话中提取姓名、偏好和重要事实，在后续对话中提供给星空。

自动提取不一定完全准确。重要信息建议在对话中明确告诉星空“请记住……”，并在设置页定期检查或删除错误记忆。

### 星空笔记本

存放在 `data/xingkong-notes.json`。这是星空自己的独立记录空间，适合保存用户明确要求记下的重要事项、人物信息和长期约定。

星空会根据对话自行判断是否需要写入；写入命令不会显示在普通聊天正文中。笔记可以在设置页查看和删除，身份类信息会得到更高优先级。

## 数据存放与备份

所有主要数据都保存在当前项目文件夹中：

| 路径 | 内容 |
| --- | --- |
| `data/chat.sqlite` | 会话、消息和聊天历史 |
| `data/emojis.sqlite` | 表情包、描述和聊天图片缓存 |
| `data/memories.json` | 长期记忆 |
| `data/xingkong-notes.json` | 星空的独立笔记本 |
| `xingkong-persona.txt` | 星空的完整角色提示词 |
| `config.json` | 公共配置 |
| `config.local.json` | 当前电脑的本地覆盖配置 |

备份时，先关闭平台，再复制整个项目文件夹即可。也可以只备份上表中的 `data`、提示词和配置文件。

项目可以移动到其他文件夹运行。为保证可移动性，请尽量在配置中使用相对路径，不要把端口、模型名或本机绝对路径写入源码。

## 配置

首次自定义时，复制示例配置：

```powershell
Copy-Item .\config.example.json .\config.local.json
```

推荐只修改 `config.local.json`。它会覆盖 `config.json` 中对应的值，便于升级代码时保留本机配置。

常用配置项：

| 配置项 | 说明 |
| --- | --- |
| `ollama.baseUrl` | Ollama 地址，默认使用本机服务 |
| `ollama.defaultModel` | 默认聊天模型 |
| `vision.defaultModel` | 默认图像理解模型 |
| `generation.maxOutputTokens` | 最大输出 token；`-1` 表示不人为限制 |
| `generation.maxThinkingCharacters` | 思考字符上限；`0` 表示不人为限制 |
| `generation.timeoutMs` | 生成超时；`0` 表示不人为限制 |
| `webSearch.enabled` | 是否允许联网搜索功能 |
| `webSearch.timeZone` | 时间工具使用的时区；留空时使用系统时区 |
| `emoji.enabled` | 是否启用表情包系统 |
| `emoji.databasePath` | 表情包数据库路径 |
| `voice.provider` | 语音提供者，例如浏览器或 GPT-SoVITS |
| `voice.autoPlay` | 是否自动播报新回复 |
| `memory.enabled` | 是否启用长期记忆 |
| `notebook.enabled` | 是否启用星空笔记本 |

修改配置后需要重新启动平台。

## 调试与维护

### 后台调试页

从页面菜单进入“调试”可以查看当前版本和服务器状态，检查 Ollama、聊天数据库、表情包数据库和语音服务，并使用安全 API 工具、运行日志和受限制的后台调试终端。

调试终端只允许项目预设的安全操作，不是任意系统命令行。

### 命令行检查

```powershell
npm run doctor
```

该命令会检查 Node.js、Ollama、模型、配置、数据库和可选语音环境。

其他维护命令：

```powershell
npm run dev
npm run build
npm start
npm run check
npm test
```

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 启动前端开发服务器 |
| `npm run build` | 构建生产版前端 |
| `npm start` | 启动本地生产服务器 |
| `npm run check` | 执行代码检查 |
| `npm test` | 运行自动化测试 |

## 常见问题

### 双击 `start.bat` 没有反应

在 PowerShell 中进入项目目录后运行 `start.bat`，查看窗口中的错误信息。常见原因包括 Node.js 版本过低、首次安装依赖失败、Ollama 没有启动、安全软件拦截脚本或旧服务器仍在占用端口。

### 消息一直没有回应

1. 打开调试页查看 Ollama 状态。
2. 运行 `ollama list`，确认选中的模型已安装。
3. 确认 Ollama 地址仍为本机正确端口。
4. 尝试较小的模型，排除显存或内存不足。
5. 使用停止按钮结束旧请求后重新发送。

### 页面打开的是旧版本

关闭旧的服务器窗口和浏览器页面，再重新运行 `start.bat`。启动器会重新构建缺失的文件并选择可用端口。必要时使用浏览器强制刷新。

### 图片无法识别

确认当前视觉模型支持图片，并检查文件格式和 8 MB 大小限制。普通文本模型即使能够收到图片描述，也不等同于真正的图像理解。

### 表情包没有显示

运行表情包导入命令，随后在表情包管理页确认数据库中存在图片和描述。如果回复中只出现了类似 `[[EMOJI:123]]` 的文字，请重启到最新服务器版本，服务器应当负责把合法编号转换成真实图片。

### 没有声音

- 先确认消息下方存在“听语音”按钮。
- 检查浏览器是否允许播放声音。
- 使用 GPT-SoVITS 时，先运行 `start-voice.bat`。
- 在调试页确认语音服务地址、参考音频和模型文件状态。
- 自动播报关闭时属于正常行为，需要手动点击播放。

## 隐私说明

聊天、图片缓存、记忆和笔记默认保存在本机项目目录，不会因为使用本平台而自动上传到云端。

以下操作可能与本机之外的服务通信：

- 开启联网搜索后发送的搜索关键词。
- 用户自行把 Ollama 或 GPT-SoVITS 地址改为远程服务器。
- 用户后续自行接入的第三方 API。

如果需要完全离线使用，请关闭联网搜索，并保持 Ollama 与语音地址指向 `127.0.0.1` 或 `localhost`。

## 已知限制

- 本地模型的回答质量取决于模型能力、提示词和可用内存。
- “无限长度”表示平台不主动截断，不代表模型拥有无限上下文。
- 自动记忆和表情包描述可能判断错误，需要人工管理。
- 联网搜索结果可能过时或不准确，重要信息应查看原始来源。
- GPT-SoVITS 的首次启动和首次合成通常较慢。
